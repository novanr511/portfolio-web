# Data analytics page design

## Design Read

Reading this as: an evidence page for a recruiter or engineering manager
evaluating a data analyst, in the existing editorial visual language, dial
**ENERGY 2 / RHYTHM 3 / MOTION 1**.

The page sits between `/projects` and the case studies. It is a catalogue,
not a landing page, so ENERGY is lower than the home page while the section
rhythm stays varied.

## Decisions and reasons (R-31)

| Decision | One-line reason |
|---|---|
| Index shows summaries only; each subject owns a detail page | A catalogue should route, not duplicate its full write-ups on one page (R-05) |
| Five items split into case studies and public-data demos | The recruiter must see shipped work and reproducible analysis separately (R-05, R-38) |
| Retired curation case study redirects to the existing essay | Older articles still link to it, so removing it must not create dead links (R-24, R-26) |
| Summary card in `/projects` links internally | It is a portal, so it must not open a new tab like the external `Live` links (R-26) |
| Every number is generated by `scripts/build_data_analytics_demos.py` | A claim the reader can rerun is stronger than a remembered figure (R-17, R-38) |
| Dataset source linked above each demo | Attribution stays next to the number it supports (R-17) |
| Limitations written into each demo | Synthetic IBM data and single-asset price data cannot support broad claims (R-36) |
| Charts generated with matplotlib, not generated artwork | The chart must represent the computed data exactly (R-22) |
| Same serif, eyebrow, colour band, and sharp cards as the rest of the site | One visual identity across pages, not a separate microsite (R-20, R-29) |
| No testimonials, client names, or fabricated company outcomes | None were supplied, and inventing them would be unverifiable (R-18, R-38) |

## Data sources

- Sales: `SampleSuperstore.csv`, public teaching dataset, 9,994 order lines.
- HR: `WA_Fn-UseC_-HR-Employee-Attrition.csv`, IBM teaching dataset, 1,470
  records, synthetic.
- Finance: `finance-charts-apple.csv`, plotly datasets, 506 trading days.

Rebuild charts and metrics with:

```
python3 scripts/build_data_analytics_demos.py
```

The script writes `scripts/data-analytics-metrics.json` and six images under
`public/images/data-analytics/`. The MDX files quote only values from that
JSON.
