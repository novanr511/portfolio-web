# High-traffic title backlog

This file reserves 50 additional titles selected for **search intent**, not for a
verified search-volume figure. No keyword-volume tool was available when this
list was built, so the selection is based on observable query patterns:

- **How to / guide** — problem-aware searchers who want a method.
- **X vs Y / compared** — decision-stage searchers close to a choice.
- **Examples / template / checklist** — searchers who want an artifact they can use.
- **What is / explained** — definitional queries with broad top-of-funnel reach.
- **Best / tools for** — commercial-investigation queries.

Every title here is registered in `docs/article-title-registry.json` under
`high_traffic_backlog`, and `scripts/check-title-duplicates.mjs` verifies that none
collides with an existing article, a reserved title, or another backlog entry.

These are **ideas, not drafts**. Treat the intent label as a hypothesis: before
writing, check the current SERP with a real tool and confirm the article answers
the question the searcher is actually asking. Do not invent volume, difficulty,
or competitor numbers.
