Web3 is not a product. It is a trust architecture.

**Direct answer:** Web3 encompasses decentralized applications built on blockchain infrastructure. Core primitives: smart contracts (self-executing code), DeFi (decentralized finance protocols), and tokenomics (economic design of tokens). Security, scalability, and user experience remain key challenges. Understanding the stack—from consensus to application—is essential for building or evaluating Web3 systems.

## Blockchain fundamentals

**Consensus:** PoW (Bitcoin), PoS (Ethereum, Solana), PoA, DPoS. Tradeoffs: security, decentralization, throughput.

**Execution:** EVM (Ethereum, L2s), SVM (Solana), Move (Aptos/Sui), WASM (Polkadot, Cosmos).

**State:** accounts (EOA, contract), storage (key-value), Merkle Patricia Trie (state root).

**Gas:** computation metering. EIP-1559 (base fee + priority fee), fee markets.

## Smart contracts

**Solidity:** primary language (EVM). Vyper (security-focused), Rust (Solana, Near), Move (Aptos/Sui).

**Patterns:** proxy (upgradeability), diamond (modular), factory (clones), multicall (batching).

**Security:** reentrancy, integer overflow, access control, oracle manipulation, MEV, flash loans. Tools: Slither, MythX, Foundry, Echidna, formal verification.

**Standards:** ERC-20 (fungible), ERC-721 (NFT), ERC-1155 (multi-token), ERC-4337 (account abstraction), ERC-4626 (vaults).

## DeFi primitives

**DEX:** AMM (Uniswap v2/v3/v4), orderbook (dYdX, Vertex), hybrid.

**Lending:** overcollateralized (Aave, Compound), undercollateralized (Prime, Maple), isolated markets (Silo, Euler).

**Stablecoins:** fiat-backed (USDC, USDT), crypto-collateralized (DAI, LUSD), algorithmic (FRAX), yield-bearing (sDAI, stETH).

**Derivatives:** perpetuals (GMX, Hyperliquid), options (Lyra, Aevo), structured products.

**Yield:** staking, liquid staking (Lido, Rocket Pool), restaking (EigenLayer), points/farming.

## Tokenomics

**Design dimensions:** utility (access, governance, payment), supply (fixed, inflationary, deflationary), distribution (team, investors, community, treasury), vesting, unlocks.

**Governance:** token voting (1 token = 1 vote), delegation, quadratic voting, conviction voting, futarchy.

**Value accrual:** fee capture, buyback/burn, staking rewards, revenue share.

**Risks:** ponzinomics, mercenary capital, regulatory (securities law), centralization.

## Security & UX

**Wallets:** EOA (seed phrase), smart contract wallets (Safe, ERC-4337), MPC (Fireblocks, Turnkey), embedded (Privy, Dynamic).

**Bridging:** lock/mint, burn/mint, liquidity networks (LayerZero, Wormhole, Axelar). Risk: bridge hacks.

**L2s:** rollups (Optimistic: Arbitrum, Optimism; ZK: zkSync, Starknet, Polygon zkEVM), validium, volition.
