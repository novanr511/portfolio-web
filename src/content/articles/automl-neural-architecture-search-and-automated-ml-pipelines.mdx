AutoML automates the tedious parts of ML. Experts design search spaces; AutoML searches them.

**Direct answer:** AutoML (Automated Machine Learning) automates the end-to-end ML pipeline: data preprocessing, feature engineering, model selection, hyperparameter optimization (HPO), neural architecture search (NAS), and model deployment. It democratizes ML for non-experts and accelerates expert workflows. Key components: search space definition, search strategy, performance estimation, and resource management.

## AutoML pipeline stages

1. **Data preprocessing:** missing value handling, encoding, scaling, feature selection.
2. **Feature engineering:** automated feature construction (Featuretools, tsfresh).
3. **Model selection:** choose algorithm family (tree, linear, neural, ensemble).
4. **Hyperparameter optimization (HPO):** search hyperparameter space.
5. **Neural Architecture Search (NAS):** search neural network architectures.
6. **Ensembling:** stack/blend top models.
6. **Deployment:** export model, generate inference code, monitoring setup.

## Hyperparameter Optimization (HPO)

Search space: learning rate, batch size, layers, dropout, regularization, optimizer.

**Strategies:**
- **Grid / Random search:** baseline.
- **Bayesian optimization (TPE, GP, SMAC):** surrogate model, acquisition function. Optuna, Hyperopt, SMAC.
- **Multi-fidelity:** Hyperband, ASHA, BOHB. Early stopping, resource allocation.
- **Population-based training (PBT):** evolutionary, online adaptation.

## Neural Architecture Search (NAS)

NAS searches neural network topology: layers, connections, operations, widths.

**Search space:** macro (entire architecture) or micro (cell repeated). DARTS (differentiable), ENAS (weight sharing), ProxylessNAS, FBNet, MobileNetV3.

**Search strategy:**
- **RL-based:** controller RNN samples architectures, reward = validation accuracy.
- **Evolutionary:** mutation/crossover, tournament selection.
- **Gradient-based (DARTS):** relax discrete search to continuous, optimize via gradient descent.
- **One-shot / weight-sharing:** train supernet once, evaluate sub-networks.

**Efficiency:** weight sharing, progressive shrinking, early stopping, proxy tasks.

## Evaluation and pitfalls

- **Data leakage in CV:** must isolate test set completely.
- **Overfitting to validation:** too many trials, use nested CV or holdout.
- **Compute cost:** NAS can take GPU-days. Use proxy tasks, weight sharing.
- **Reproducibility:** seed control, config versioning.
- **Deployment gap:** AutoML models may need optimization (quantization, distillation) for production.
