Images are just arrays of numbers. Computer vision makes them meaningful.

**Direct answer:** Computer vision enables machines to interpret and understand visual data. Convolutional Neural Networks (CNNs) are the backbone, using convolutional layers to learn spatial hierarchies of features. Transfer learning adapts pretrained models (ResNet, EfficientNet, ViT) to new tasks with less data. Object detection (YOLO, Faster R-CNN, DETR) localizes and classifies multiple objects in an image.

## Convolutional Neural Networks

**Convolutional layers:** learn spatial filters (kernels) that slide over the input, detecting edges, textures, patterns. Stacking layers builds hierarchy: edges → textures → parts → objects.

**Pooling:** reduces spatial dimensions (max/avg pooling), increases receptive field, provides translation invariance.

**Architecture evolution:**
- **LeNet / AlexNet:** early breakthroughs.
- **VGG:** deep stacks of 3x3 convolutions.
- **ResNet:** residual connections enable very deep networks (50–152 layers).
- **EfficientNet:** compound scaling (depth, width, resolution) for efficiency.
- **Vision Transformers (ViT):** patch-based, attention-based, large-scale pretraining.

## Transfer learning

Pretrain on large dataset (ImageNet-21k, JFT-300M) → fine-tune on target task.

**Strategies:**
- **Feature extraction:** freeze backbone, train new head only. Fast, low data needed.
- **Fine-tuning:** unfreeze some/all layers, train with low LR. Better performance, more data/compute.
- **Linear probing:** freeze backbone, train linear classifier on frozen features. Baseline.

**Modern practice:** pretrained on ImageNet-21k or JFT, fine-tune with low LR (1e-4 to 1e-5), use weight decay, gradient clipping, mixed precision.

## Object detection

**Two-stage (region proposal + classification):**
- **Faster R-CNN:** Region Proposal Network (RPN) + ROI pooling + classifier/regressor. Accurate, slower.
- **Mask R-CNN:** adds segmentation mask branch for instance segmentation.

**Single-stage (dense prediction):**
- **YOLO (v3–v10):** grid-based, anchor-based or anchor-free. Very fast, real-time.
- **SSD:** multi-scale feature maps, default boxes.
- **RetinaNet:** focal loss for class imbalance.

**Transformer-based:**
- **DETR:** set prediction with bipartite matching, transformer encoder-decoder. No NMS needed.
- **Deformable DETR:** deformable attention for efficiency.

## Key concepts

**IoU (Intersection over Union):** overlap between predicted and ground truth boxes.
**mAP (mean Average Precision):** standard detection metric across IoU thresholds.
**NMS (Non-Maximum Suppression):** removes duplicate overlapping boxes.
**Anchor boxes:** predefined box shapes for regression targets.

## Practical tips

- **Data augmentation:** mixup, cutmix, mosaic, copy-paste, photometric distortions.
- **Label smoothing, mixup, cutmix:** regularization for classification.
- **Freeze batch norm statistics** when fine-tuning with small batches.
- **Test-time augmentation (TTA):** average predictions over augmented versions.

## Further Reading

- Kaiming He et al., 2016. [Deep Residual Learning for Image Recognition](https://openaccess.thecvf.com/content_cvpr_2016/html/He_Deep_Residual_Learning_CVPR_2016_paper.html) — Residual connections, the architecture that made very deep CNNs trainable.
- Shaoqing Ren et al., 2015. [Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks](https://proceedings.neurips.cc/paper_files/paper/2015/hash/14bfa6bb14875e45bba028a21ed38046-Abstract.html) — The two-stage detector that introduced region proposal networks.
- Joseph Redmon et al., 2016. [You Only Look Once: Unified, Real-Time Object Detection](https://openaccess.thecvf.com/content_cvpr_2016/html/Redmon_You_Only_Look_CVPR_2016_paper.html) — The single-stage detector that reframed object detection as a regression problem.
- Tsung-Yi Lin et al., 2017. [Focal Loss for Dense Object Detection](https://openaccess.thecvf.com/content_iccv_2017/html/Lin_Focal_Loss_for_ICCV_2017_paper.html) — The class-imbalance loss that made single-stage detectors work.
- Alexey Dosovitskiy et al., 2020. [An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale](https://arxiv.org/abs/2010.11929) — The vision transformer that moved vision models beyond CNNs.
- Nicolas Carion et al., 2020. [End-to-End Object Detection with Transformers](https://arxiv.org/abs/2005.12872) — Set prediction with bipartite matching, removing the need for non-maximum suppression.
- Mingxing Tan and Quoc V. Le, 2019. [EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks](https://arxiv.org/abs/1905.11946) — Compound scaling of depth, width, and resolution.
