Deep learning is pattern recognition at scale.

**Direct answer:** Deep learning uses multi-layered neural networks to learn representations from data. Neural networks transform inputs through layers of weighted connections; backpropagation adjusts those weights using gradient descent to minimize error. Practical use cases include image classification, text generation, recommendation, and time-series forecasting—where data is abundant and patterns are complex.

## Neural network fundamentals

A neural network consists of layers:

- **Input layer:** receives features (pixels, word embeddings, sensor readings).
- **Hidden layers:** transform inputs through weighted sums and non-linear activation functions (ReLU, sigmoid, tanh).
- **Output layer:** produces predictions (class probabilities, regression values).

Each connection has a weight; each neuron has a bias. The network learns by adjusting weights to reduce prediction error.

A simple feedforward network:
```text
Input → Hidden Layer 1 → Hidden Layer 2 → Output
```

## Backpropagation: how networks learn

Backpropagation computes gradients of the loss function with respect to each weight:

1. **Forward pass:** compute prediction and loss.
2. **Backward pass:** propagate error backward using the chain rule, computing gradients for every weight.
3. **Update:** gradient descent adjusts weights in the direction that reduces loss:
   `weight = weight - learning_rate × gradient`

Repeat over many epochs and batches. The learning rate controls step size; too high diverges, too low crawls.

## Common architectures

- **Feedforward networks:** for tabular data and simple classification.
- **Convolutional Neural Networks (CNNs):** for images and spatial data. Use convolutional layers to detect local patterns.
- **Recurrent Neural Networks (RNNs) and LSTMs:** for sequences (text, time series). Maintain hidden state across steps.
- **Transformers:** attention-based models for text and multimodal data. Dominant in NLP and increasingly in vision.

## Practical use cases

Deep learning excels when:

- **Data is abundant:** thousands to millions of labeled examples.
- **Patterns are complex:** images, speech, unstructured text.
- **Feature engineering is impractical:** the model learns features automatically.

It is overkill for:

- **Small tabular datasets:** gradient boosting or logistic regression often performs better with less data.
- **Interpretability requirements:** neural networks are black boxes.
- **Strict latency constraints:** smaller models are faster and cheaper.

## Training considerations

- **Overfitting:** model memorizes training data but fails on new data. Use dropout, weight decay, early stopping, and more data.
- **Underfitting:** model is too simple. Increase capacity or train longer.
- **Data quality:** garbage in, garbage out. Clean labels, balanced classes, and representative splits matter more than architecture tweaks.
